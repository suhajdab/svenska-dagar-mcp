# Security policy

## Supported versions

Only the latest published version of `@onereason/svenska-dagar-mcp` receives
security fixes. Users should update promptly when a new version is released.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting flow from the repository's **Security** tab and
include:

- the affected package version;
- reproduction steps or a proof of concept;
- the expected impact;
- any known mitigations.

You can expect an acknowledgement within seven days. Confirmed issues will be
fixed in a new immutable npm release; published versions will never be replaced.
